### Hi, I’m Mia 👋
I’m a software engineer based in Germany specializing in **cross-platform Swift development, data sovereignty and software security**.

My focus is on breaking Swift out of Apple’s walled garden by building the foundational databse, security and infrastructure tools needed to run Swift Apps natively on Windows, Linux and Android. Swift is so much more than just Apple.

---

### Core Projects & Ecosystem Contributions
#### [amethystsoft](https://github.com/amethystsoft) (The name I publish under)
- **[Amethyst Vein](https://github.com/amethystsoft/vein.git):**: A cross-platform, declarative database framework, supporting encryption, inspired by SwiftData. Built from the ground up for non-Apple (and Apple) platforms.
- **[KeyringAccess](https://amethystsoft/keyringaccess.git):** KeychainAccess-like secure credential management for linux via the SecretService API.

#### Ecosystem Contributions
- **[SwiftCrossUI](https://github.com/moreSwift/swift-cross-ui.git):** Core contributor to the primary, declarative, cross-platform UI framework for Swift.
